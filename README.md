# Provably Secure and Robust Audio Steganography under Multi-Format Low-Bitrate Compression

This repository contains the official implementation of the paper:

**Provably Secure and Robust Audio Steganography under Multi-Format Low-Bitrate Compression**

Published in: IEEE Transactions on Information Forensics and Security (Volume: 20)


# Startup

1. Download the Ezaudio checkpoints from https://huggingface.co/OpenSound/EzAudio/tree/main to the root folder as `Ezaudio`

2. `embed_msg.py` and `extract_msg.py` provide scripts for single audio inference.
